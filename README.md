# ÁUDIO — aulas neurais PT-BR

Pipeline gratuito para transformar roteiros em MP3 usando Edge TTS e GitHub Actions.

## Padrão de voz
- Idioma: português do Brasil
- Voz inicial: pt-BR-AntonioNeural
- Velocidade: -5%
- Pitch: +0Hz

O workflow `Gerar audio neural` pode ser executado manualmente e publica o MP3 como artifact.
